## Project structure

- `artifacts/portfolio` — frontend portfolio website
- `artifacts/api-server` — backend API for contact and server logic
- `lib` — shared libraries and generated client/schema code
- `attached_assets` — media and reusable assets

## How to run locally

### Frontend

```bash
cd artifacts/portfolio
set PORT=3000
set BASE_PATH=/
npx vite --config vite.config.ts --host 0.0.0.0 --port 3000
```

### Backend

```bash
cd artifacts/api-server
set PORT=5000
pnpm run dev
```

### Full workspace setup

```bash
cd ar-datafolio
pnpm install
pnpm run typecheck
```
